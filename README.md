# Mandelbrot Set Animation - Trippy Edition

An interactive 2D Mandelbrot set explorer with:
- Guided descent into 4 famous boundary regions
- Adaptive resolution rendering
- Julia set flight mode
- Smooth escape-time coloring
- Full manual control (zoom, pan, dive)

## Usage
Simply open `index.html` in a modern web browser.

## Controls
- **Scroll**: Zoom at cursor
- **Drag**: Pan
- **Double-click**: Dive in
- **Shift+Double-click**: Rise out
- **Space**: Toggle tour
- **J**: Toggle Julia mode
- **R**: Replay current stop
- **1-5**: Switch color palette
- **H**: Hide HUD
